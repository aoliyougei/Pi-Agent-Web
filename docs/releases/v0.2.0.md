# Pi-Agent-Web v0.2.0

## 中文

基于 `v0.1.0..v0.2.0` 的变更。

- 新增共享 Pi Agent 后端配置，支持 HTTP/HTTPS、名称、地址、端口和 Token；各浏览器独立选择连接。
- Web 可独立启动，无需预先提供后端或 Token；新增独立 Compose 部署。
- Token 在 Web 专用持久化卷中保存，查询不返回凭据；删除当前后端不会自动回退。
- 设置页新增圆角 Agent 图标、右键菜单、长按及键盘操作，末尾 '+' 添加后端；修复表单滚动裁切。
- 左下角新增 Pi Agent 快捷入口，模型设置仍保留。
- Web 增加配置数据卷与 Kubernetes PVC；readiness 不依赖 Agent 在线。

Docker：`registry.aoliyougei.com/aoliyougei/pi-agent-web:0.2.0`（linux/amd64）。

注意：只向可信用户开放 Web，所有访问者均可管理共享后端；Token 文件为明文凭据，需保护数据卷与备份。保留配置卷，勿执行 `down -v`。Kubernetes Web 使用单副本 Recreate 更新策略。未升级现有依赖，安装审计报告的 23 项漏洞尚未处理。未发布 npm 包，未修改 Agent 运行时或协议。

## English

Changes since `v0.1.0`:

- Shared HTTP/HTTPS Pi Agent connection profiles with browser-specific selection.
- Standalone Web startup without a preconfigured backend or Token, plus Web-only Compose deployment.
- Persistent server-side Tokens with redacted API responses and no automatic fallback for deleted selections.
- Rounded Agent launch icons, context menu, touch-and-hold and keyboard support, a final '+' tile, and scroll clipping fix.
- Pi Agent sidebar shortcut; model settings remain available.
- Dedicated Web configuration volume/PVC and readiness independent of Agent availability.

Docker: `registry.aoliyougei.com/aoliyougei/pi-agent-web:0.2.0` (linux/amd64).

Expose Web only to trusted users. Tokens are plaintext credential files: protect volumes and backups. Preserve the configuration volume. Kubernetes uses a single Web replica with Recreate updates. Existing dependencies were not upgraded; the installation audit reported 23 unresolved vulnerabilities. No npm package publication or Agent runtime/protocol changes.
