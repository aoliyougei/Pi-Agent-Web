# Pi-Agent-Web v0.2.1

## 中文

- 适配 Pi-Agent-RPC 0.2.0 / Pi 1.2.0，同时保留 Pi 0.84.4 支持及协议、能力校验。
- 新建对话页动态展示当前后端的 pi-agent-rpc 版本，悬浮显示底层 Pi 版本；读取失败清除旧版本。
- 移除新建页上游更新链接，Web 版本改为从 release.json 读取并显示 pi-agent-web v0.2.1。
- 新增不缓存的版本查询 BFF，不向浏览器暴露服务凭据或上游错误。

没有修改 Agent 源码或协议。验证覆盖测试、类型检查及 RPC 0.2.0 镜像的版本、目录、模型和会话列表接口；尚未覆盖真实模型对话和完整 SSE。默认目录在测试容器中正常，用户部署中的原问题尚未确认。此次 GitHub 发布不包含新 Docker 正式版；部署示例仍引用此前已发布的 0.2.0 镜像。现有依赖漏洞未在此版本处理。

## English

- Support Pi-Agent-RPC 0.2.0 / Pi 1.2.0 while retaining Pi 0.84.4 support, protocol validation and required-capability checks.
- Show the connected RPC server version dynamically, with the underlying Pi version in a tooltip; clear stale versions on failure.
- Remove the upstream update link from new chats and display pi-agent-web v0.2.1 from release.json.
- Add an uncached version BFF without exposing service credentials or upstream errors.

No Agent source or protocol changes. Tests, type checks and selected RPC 0.2.0 image endpoints were verified; real model prompts and full SSE were not tested. The user's deployed default-directory issue remains unconfirmed. This GitHub release does not publish a new production Docker image; deployment examples still reference the previously published 0.2.0 image. Existing dependency vulnerabilities remain unresolved.
